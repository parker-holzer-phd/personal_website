## Context

This repository is a fork of the material accompanying the *Deployment of Machine Learning Models* course. It is included as a learning resource from my older account; the course framework and examples are not presented as my original work.

## What it covers

The repository follows machine-learning work from exploratory notebooks and feature engineering into model packages, prediction APIs, tests, continuous integration, and container deployment. A regression pipeline combines preprocessing with a Lasso model.
