## An earlier home for the work

This repository holds the source for my earlier personal website, built with Jekyll and the Minimal theme for GitHub Pages.

## What it contains

Markdown pages collect research descriptions, paper links, and project figures. Layouts and styles handle presentation, while the assets directory holds the original visualizations reused in this portfolio.

The file map above represents the repository’s structure. The repository is an archive: its biography and news describe that earlier period.
