## The goal

Make Python approachable through examples that readers can run and change.

## The tutorials

The repository has a beginner track and an introduction for R users. The R-user notebook covers Python syntax, lists, strings, functions, plotting, and equivalents of familiar R operations.

## Learning by doing

The accompanying visualization comes from the notebook’s NumPy and Matplotlib example fitting a quadratic relationship to simulated data. Open the notebooks to explore the code and its saved outputs.
